## 2. Six-Semester Roadmap

### Semester 1 --- Foundations (Current)

**University subject areas:** Programming fundamentals / Problem Solving
using C; Engineering Mathematics; computer fundamentals and digital
logic; communication skills and other first-year foundation courses.

**Technical skills** - Strengthen Python fundamentals: conditions,
loops, functions, strings, lists and dictionaries. - Practise C
programming and basic debugging. - Learn Linux navigation, files,
permissions and common Bash commands. - Learn Git/GitHub: repositories,
clone, status, add, commit, push and pull. - Understand number systems,
binary arithmetic and basic computer concepts.

**Projects and milestones** - Organise the CSE103 lab repository using
`src/`, `tests/` and `docs/`. - Create a GitHub portfolio repository. -
Build small Python and C programs and document how to run them.

**Certification goal:** Prepare for and attempt HackerRank Python
(Basic).

**Platforms:** HackerRank, freeCodeCamp, GitHub Skills and Linux
command-line practice.

**Weekly habit:** Spend 3--4 hours per week on focused practice outside
regular classes.

**Three monthly targets for the current semester** 1. Month 1: Solve at
least 15 beginner Python problems and practise basic C programs. 2.
Month 2: Complete the Git/GitHub workflow and publish organised lab work
on GitHub. 3. Month 3: Finish 15 more Python problems, revise Linux
commands and attempt the HackerRank Python (Basic) assessment.

### Semester 2 --- Core Computer Science

**University subject areas:** Data Structures and Programming; Discrete
Mathematics / Engineering Mathematics; Object-Oriented Programming;
computer organisation or other second-semester core courses.

**Technical skills** - Learn Python OOP: classes, objects, inheritance,
file handling and exceptions. - Learn C++ fundamentals and practise
problem-solving. - Study arrays, strings, linked lists, stacks, queues,
trees and searching/sorting. - Improve command-line, Git branching and
debugging skills.

**Projects:** Create a DSA implementation repository with at least five
data structures implemented from scratch. Build a console-based student
or library record manager using file handling.

**Certification goal:** Complete a beginner programming or Python course
with a verifiable certificate, if available.

**Practice target:** Solve 40--50 beginner DSA problems gradually; focus
on understanding rather than speed.

### Semester 3 --- Databases, Web and CS Fundamentals

**University subject areas:** Database Management Systems; Computer
Networks; Operating Systems; Design and Analysis of Algorithms or
related core courses.

**Technical skills** - Learn SQL, MySQL, joins, keys, constraints and
indexes. - Strengthen HTML, CSS and JavaScript. - Understand processes,
memory, file systems, networking and HTTP basics. - Practise Git
collaboration and clear project documentation.

**Projects:** Build a Student Record Management System using Python and
MySQL. Create a responsive personal portfolio website.

**Certification goal:** Complete a SQL or database fundamentals course;
consider freeCodeCamp Responsive Web Design.

**Practice target:** Solve 20--25 DSA problems and complete regular SQL
exercises.

### Semester 4 --- Applied Development and Mathematics for AI

**University subject areas:** Probability and Statistics; Design and
Analysis of Algorithms; Software Engineering; relevant mathematics and
core CSE subjects.

**Technical skills** - Learn probability, statistics, linear algebra and
calculus used in ML. - Learn NumPy, Pandas and Matplotlib. - Build REST
APIs using Flask or FastAPI. - Learn testing, debugging, JSON, API
requests and database integration. - Explore introductory machine
learning concepts.

**Projects:** Develop a Task Manager or Student Portal using Python, a
database and a web interface. Complete one small data analysis project
using a public dataset.

**Certification goal:** Complete an introductory machine learning or
Python data analysis course. Explore free AWS Skill Builder foundational
learning.

**Career target:** Start applying for internships and networking during
Semester 4.

### Semester 5 --- Specialisation: Data Science and AI / ML

**Core skills** - Data analysis with NumPy, Pandas and Matplotlib. -
Statistics, probability, feature engineering and data preprocessing. -
Machine learning with Scikit-learn: regression, classification,
clustering and model evaluation. - Deep learning fundamentals and neural
networks. - Introduction to PyTorch; understand when TensorFlow is
useful. - Responsible AI, data privacy and model limitations.

**Projects:** Build an end-to-end machine learning project using a real
dataset. Build a second project that exposes a trained model through a
REST API or simple web interface. Publish code, documentation and
results on GitHub.

**Personal project idea --- Smart Canteen Queue Management System:**
Create a system that lets students view queue status and place orders or
join a virtual queue. Begin with a web application and database; later
explore demand prediction using historical order data.

**Certification goal:** Complete relevant Kaggle micro-courses (Python,
Pandas and Intro to Machine Learning) or an equivalent course.

**Career target:** Apply for a summer internship in Python development,
data analytics or machine learning.

### Semester 6 --- Industry Readiness and Capstone

**University subject areas:** Final-year project / capstone preparation;
relevant electives in AI, ML, data science or software engineering;
professional communication and placement preparation.

**Technical skills** - Strengthen ML model selection, evaluation, tuning
and deployment. - Learn basic Docker, cloud deployment and CI/CD
concepts. - Practise DSA, SQL, Python coding interviews and technical
communication. - Learn to explain project architecture, decisions,
limitations and results.

**Projects:** Complete a capstone project in AI/ML with a 3--4 member
team and faculty mentor. Deploy at least one project where feasible.
Maintain at least three well-documented technical projects and five
meaningful GitHub repositories.

**Career targets:** Apply for internships and entry-level opportunities
aligned with AI/ML, data science or Python development. Prepare a
targeted resume, LinkedIn profile and GitHub portfolio. Practise mock
interviews and aim for 100 DSA problems across the six-semester plan.

**Certification goal:** Choose one credible certification or course
based on target role requirements. Prioritise projects and demonstrable
skills over collecting certificates.
